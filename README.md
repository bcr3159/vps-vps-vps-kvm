## 搬瓦工注册步骤

### 1. 打开注册页面

进入页面后选择 **Register**，进入新账户表单。若已经有账号，改用登录入口即可，不需要重复注册。

### 2. 填写账户资料

按表单填写名、姓、邮箱、密码和账单信息。邮箱尤其重要：建议不要使用临时邮箱，也不要随手填一个之后无法访问的地址。账户通知和密码找回都依赖它。

密码栏通常需要再次输入确认。填写完成后，检查邮箱拼写、国家或地区和地址，再提交。若页面提示某一项格式不正确，按页面要求修正，不要为了通过表单填写虚假资料。

### 3. 同意服务条款并提交

阅读并勾选服务条款后提交注册。若页面要求额外验证，按屏幕提示完成。注册页面的显示内容可能会随账户状态或地区变化，因此以当前页面实际要求为准。

### 4. 登录账户

注册完成后回到 Client Area，用注册邮箱和密码登录。若暂时无法登录，先检查邮箱是否填错、密码是否输错，以及页面是否要求完成验证；仍无法解决时，可通过账户页面的密码重置或支持入口处理。

## 注册之后，怎样购买搬瓦工 VPS？

账号建好后，还要选择服务。常见流程是进入 VPS 方案页面，选择套餐和可用机房，确认账单周期，再把服务加入购物车并结账。

### 1. 先按用途选线路与配置

别只盯着价格。至少先比较以下项目：

- **内存、CPU 与存储**：影响能运行多少服务，以及应用是否容易触及资源上限。
- **月流量和端口速度**：流量额度与端口标称速度不是一回事；前者是周期配额，后者是连接带宽上限。
- **机房和线路**：不同套餐可选的位置与网络并不相同。面向中国大陆用户时，官网将 CN2 GIA/CTGNet 作为中国方向网络方案介绍；普通线路与优化线路不能当作同一档配置。
- **管理方式**：搬瓦工的 VPS 是 self-managed，需要用户自行管理系统。KiwiVM 可用于开关机、重装系统、查看使用情况、迁移机房等操作，但它不等同于代运维服务。

如果只是学习 Linux 或部署小型个人项目，先看入门资源是否够用；若业务对中国方向网络质量更敏感，再认真比较对应线路的价格与机房。不要为了“以后可能用得上”直接买大规格，闲置的 CPU 和流量不会替你省钱。

### 2. 选择计费周期和机房

不同方案的可选周期并不完全一致。官方公开的基础 KVM 页面目前列出年付、半年付和月付等不同组合；其他产品页面可能提供月付、季付、半年付或年付。**具体以对应套餐结账页显示为准**，不要用另一个套餐的周期推断当前选项。

机房同样按具体方案而异。某些方案支持多个位置或之后迁移，另一些则与特定机房和线路绑定。下单前确认页面列出的地点、迁移条件及服务规格，尤其是购买理由主要来自网络线路时。

### 3. 检查购物车与优惠码

加入购物车后，核对套餐名称、机房、账期、应付金额和续费周期。若持有优惠码，可在促销代码栏输入并验证；只有结账页面明确显示折扣生效，才应把它算进最终价格。网上流传的代码可能已经过期，也可能不适用于某些产品，别只凭文章或论坛旧帖里的折扣数字判断。

## 搬瓦工注册与购买时的常见问题

### 注册账号要先买 VPS 吗？

不一定。注册账户和购买服务是分开的操作。你可以先创建账户，之后再登录选择 VPS；只有完成套餐配置和付款，才会产生对应订单。

### 注册必须填写公司名称吗？

官网表单包含公司名称字段，但个人注册可按实际情况处理。其他账单信息应填写真实、可接收通知的内容。

### 买完之后搬瓦工会帮忙配置服务器吗？

官网把这类服务标为 self-managed。KiwiVM 提供控制面板和服务器基础管理功能，但安装应用、设置防火墙、更新系统和维护服务通常需要用户自行负责。完全不熟悉 Linux 命令行的话，最好先确认自己能完成所需管理工作，或准备好相应技术支持。

### 注册时看见的价格就是最终付款金额吗？

不一定。不同账期、产品选项、促销代码和购物车配置会影响应付金额。以最终结账页为准，特别检查币种、服务周期、优惠是否实际应用，以及下一周期的续费金额。

### 应该选基础 KVM 还是 CN2 GIA？

先看项目的访问人群和网络要求。基础 KVM 的公开入门价格更低；官网对 CN2 GIA 的介绍则强调中国方向网络质量。若访问者主要不在中国大陆，或项目对延迟要求不高，更贵的线路未必带来相称收益。若业务访问对中国方向网络稳定性敏感，则应进一步比较该线路套餐的机房、资源和价格，而不是只依据线路名称下结论。
